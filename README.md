# Pergola Lite — 3D konfigurátor

Jednoduchý 3D konfigurátor **primárně zaměřený na pergolu** (Alux-style).

- Plný konfigurátor s realistickou scénou: `../pergola-3d` → http://localhost:3002  
- Tento lite: http://localhost:3003

```bash
npm run dev -- --port 3003
```

Kontext domu je jen schéma (plocha trávníku + bílá hmota při kotvení ke zdi). Detail je v pergole.
